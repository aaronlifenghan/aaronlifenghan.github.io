# Lifeng Han academic homepage

GitHub Pages static website for `https://aaronlifenghan.github.io`.

## Publish
1. Create a **public** GitHub repository named `aaronlifenghan.github.io`.
2. Upload `index.html`, `style.css`, and `Lifeng_Han_CV.pdf` into the repository **root** (not inside a folder).
3. Open **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**, then **main** and **/(root)**, and save.
4. Visit `https://aaronlifenghan.github.io` after publication.

## Edit
- Edit `index.html` for text, links, publications and talk titles.
- Edit `style.css` for appearance.
- Replace `Lifeng_Han_CV.pdf` to update the downloadable CV.
- The hero uses a neutral `LH` monogram; it is intentionally not a fabricated photo.
- Review public contact details and publication statuses before publishing.
